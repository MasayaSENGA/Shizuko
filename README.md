# Shizuko

Windows 11向けの音楽CD作成アプリです。Windows Media Playerに依存せず、Windows標準のIMAPI 2.0を使います。

## 起動

`Shizuko.bat` をダブルクリックします。起動中はコマンドプロンプトの窓が開いたままになり、起動に失敗したときはエラーを表示して待機します。

PowerShellから起動する場合は、Windows PowerShell 5.1でこのフォルダを開き、次を実行します。

```powershell
.\Shizuko.ps1
```

## 対応範囲

- WAV、MP3、M4A/AAC、WMA、FLAC、OGG/Opus、MP4、AIFFなどの音声ファイルの追加
  - 44.1 kHz・16 bit・ステレオのPCM WAVはそのまま使います。
  - それ以外（MP3などの圧縮形式、他のサンプルレートやビット深度のWAVなど）はWindows Media Foundationで44.1 kHz・16 bit・ステレオに変換して使います。変換結果は一時フォルダーに置かれ、アプリ終了時に削除されます。
- ドラッグ＆ドロップ（フォルダーを落とすと直下の対応ファイルを名前順に追加）、曲順変更、合計時間表示
- 光学ドライブ選択とCD-R/CD-RWへの音楽CD書き込み

読み込めるかどうかはWindowsに入っているコーデックに依存します。たとえばOGG/OpusやFLACは、環境によっては別途コーデックの追加が必要で、非対応の場合は追加時にエラーを表示します。コピー防止（DRM）付きのファイルは読み込めません。書き込みにはWindows標準のIMAPI 2.0とADODB.Streamを利用します。書き込みはバックグラウンドで行い、書き込み中は操作とアプリの終了ができません。

Smart App Controlや組織のアプリ制御ポリシーがスクリプトをブロックする環境では起動できない場合があります。このアプリは制御を回避しません。
